>
> **Test Data** is built by business role, not copied from the prototype's mock rows. `KR` is the only country seeded taxable with no declaration; every other ISO code is seeded zero-rated and requires a declaration. The codes `JP`, `AT`, `AE`, `VN`, `GS`, `TR`, `AQ` only play the part of "a country other than KR" — substituting any other ISO code still runs correctly.
>
> **Korean strings:** roughly 30 interface strings are kept in English by the customer's own decision and are marked as pending in the glossary. These test cases verify bilingual text only against the attested Korean set plus the Korean messages in the SRS's error table. The prototype currently renders only the English half of four message groups — these test cases follow the SRS, and the difference is logged in `SPEC_GAP_QnA_US089_v1.9_2026-09-24.md`. **The interim front-end build for this screen also ships unconfirmed Korean strings for `VAT treatment`/`Export declaration`/`Required`/`Not required` (`부가세 처리`/`수출 신고`/`필요`/`불필요`, SRS v1.8/v1.9) — the affected test cases carry an explicit note; seeing Korean there on the real build is a known, logged discrepancy, not a defect to raise blind.
>
